Vertical Circular Motion and Energy

Non-uniform circular motion influenced by gravity.

1. Non-Uniform Nature

When an object tethered to a string moves in a vertical circle, gravity acts as a tangential force, changing the object's speed at every point. This is a classic application of the Work-Energy Theorem.

2. Tension Analysis

At any point (angle \(\theta\) from the bottom), the tension \(T\) in the string is:

\[ T - mg \cos \theta = \frac{mv^2}{R} \]
  • At Bottom (\(\theta = 0\)): \( T_L = mg + \frac{mv_L^2}{R} \) (Maximum Tension)
  • At Top (\(\theta = \pi\)): \( T_H = \frac{mv_H^2}{R} - mg \) (Minimum Tension)

3. Critical Values for a String

For the object to complete the circle without the string slacking, the tension at the top must satisfy \(T_H \geq 0\).

\[ v_{Top} \geq \sqrt{gR} \] \[ v_{Bottom} \geq \sqrt{5gR} \]
If the velocity at the bottom is between \(\sqrt{2gR}\) and \(\sqrt{5gR}\), the string will slack somewhere in the upper half, and the particle will follow a parabolic path until the string becomes taut again.
