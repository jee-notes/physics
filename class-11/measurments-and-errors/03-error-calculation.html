Calculating Error Metrics

Quantifying the magnitude and significance of uncertainty.

1. True Value (Arithmetic Mean)

In the absence of a known standard, the arithmetic mean of multiple readings is taken as the "true value" (\(a_{mean}\)).

\[ a_{mean} = \frac{a_1 + a_2 + ... + a_n}{n} \]

2. Absolute Error (\(\Delta a\))

The magnitude of the difference between the true value and the individual measured value.

\[ \Delta a_i = |a_{mean} - a_i| \]

Mean Absolute Error: The arithmetic mean of all absolute errors.

\[ \Delta a_{mean} = \frac{|\Delta a_1| + |\Delta a_2| + ... + |\Delta a_n|}{n} \]

3. Relative and Percentage Error

These metrics represent the error relative to the size of the quantity being measured.

\[ \text{Relative Error} = \frac{\Delta a_{mean}}{a_{mean}} \] \[ \text{Percentage Error} = \frac{\Delta a_{mean}}{a_{mean}} \times 100\% \]
Percentage error tells you how "significant" the error is. A 1cm error in a 10cm measurement is huge (10%), but a 1cm error in a 1km measurement is negligible (0.001%).
