Resolution of Vector

Breaking down a vector into components.

What is Resolution?

Resolution means breaking down a quantity into components for convenience of calculation.

For example, if we want to calculate

\[ 9+7 \]

we may resolve \(9\) as \(10-1\):

\[ 9+7=10-1+7=10+6=16 \]

The original number is not changed; it is simply represented as a combination of simpler quantities that are more convenient to work with.

Similarly, a vector can be resolved into a set of component vectors whose vector sum is the original vector.

\[ \boxed{\vec A=\vec A_1+\vec A_2+\vec A_3+\cdots} \]

Orthogonal Resolution

Orthogonal resolution can be applied to both \(2D\) and \(3D\) vectors. For simplicity, we first discuss the \(2D\) case. Here, all the vectors are coplanar, so we can restrict ourselves to a single plane.

Dimensionality is defined when the co-ordinate axes and unit vectors are defined.
As we have not yet defined them, we will only use geometric implication of 2D as a flat plane.

Suppose there is a vector \(\vec A\) and we want to resolve it into components such that all the components are non-collinear and co-planar.

There are two possibilities: the components may be rectangular or non-rectangular.

In rectangular resolution, the component vectors are mutually perpendicular. In a plane, once one direction is chosen, its perpendicular direction is fixed, apart from its opposite direction. This can be visualized from the four directions

\[ \hat i,\quad \hat j,\quad -\hat i,\quad -\hat j \]

which divide the full \(360^\circ\) around the point into four equal angles:

\[ \frac{360^\circ}{4}=90^\circ \]

Thus, \(\hat j\) is perpendicular to both \(\hat i\) and \(-\hat i\). There is no third independent direction in the same plane that is also perpendicular to these directions.

Therefore, a vector in \(2D\) can have at most two non-zero rectangular components:

\[ \boxed{\vec A=A_x\hat i+A_y\hat j} \]

Once the two perpendicular directions are specified, these two components are uniquely determined.

In non-rectangular resolution, the component directions need not be perpendicular. There is no corresponding \(90^\circ\) restriction, so the same vector can be resolved into infinitely many different sets of non-collinear, coplanar components.

Rectangular resolution is unique because, in a plane, perpendicular directions are fixed once one direction is chosen. Non-rectangular resolution has no such restriction and therefore does not have a unique set of components.
