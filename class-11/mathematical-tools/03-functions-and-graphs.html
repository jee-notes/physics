Functions and Graphical Analysis

Visualizing relationships between physical variables.

1. What is a Function?

In physics, a function represents a causal relationship. For example, the position of a car is a function of time: \(s = f(t)\).

  • Independent Variable: The "Cause" (usually plotted on the x-axis, like time).
  • Dependent Variable: The "Effect" (usually plotted on the y-axis, like velocity).

2. Slopes and Intercepts

The slope (\(m\)) of a graph represents the rate of change.

\[ m = \frac{\Delta y}{\Delta x} = \tan \theta \]
In a Position-Time graph, the slope is Velocity. In a Velocity-Time graph, the slope is Acceleration.

The y-intercept (\(c\)) represents the initial value of the dependent variable when the independent variable is zero (e.g., initial velocity \(u\) at \(t = 0\)).

3. Sign Conventions in Graphs

Graphical analysis helps in "Visual Sign Management":

  • Positive Slope: The dependent variable is increasing.
  • Negative Slope: The dependent variable is decreasing.
  • Area under the Curve: Represents the product of the two variables (e.g., Area under a V-T graph is Displacement).
