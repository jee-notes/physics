Normal Modes of Vibration & Sonometer

Resonant standing wave frequencies, boundary mode quantization, and harmonic overtone spectra.

Boundary Conditions for String Fixed at Both Ends

Consider a uniform flexible string of length \( L \) stretched under tension \( T \) and clamped rigidly at both ends \( x = 0 \) and \( x = L \).

Because both ends are immovable, the total displacement must satisfy the Dirichlet boundary conditions for all time \( t \):

\[ y(0, t) = 0 \quad \text{and} \quad y(L, t) = 0 \]

The general equation of a standing wave on the string is:

\[ y(x, t) = \left[ 2A \sin(kx) \right] \cos(\omega t) \]

The condition \( y(0,t) = 0 \) is automatically satisfied by \( \sin(0) = 0 \). Applying the second boundary condition at \( x = L \):

\[ y(L, t) = 2A \sin(kL) \cos(\omega t) = 0 \implies \sin(kL) = 0 \]

This implies that \( kL \) must be an integer multiple of \( \pi \):

Allowed Wavelengths (String Fixed at Both Ends): \[ k_n L = n\pi \implies \left(\frac{2\pi}{\lambda_n}\right) L = n\pi \implies \lambda_n = \frac{2L}{n} \quad (n = 1, 2, 3, \dots) \]

Fundamental Mode (1st Harmonic) and Overtones

Since only discrete wavelengths \( \lambda_n = \frac{2L}{n} \) can exist, the string can oscillate in steady resonance only at discrete, quantized natural frequencies \( f_n = \frac{v}{\lambda_n} \):

Quantized Natural Frequencies: \[ f_n = \frac{n v}{2L} = \frac{n}{2L} \sqrt{\frac{T}{\mu}} \quad (n = 1, 2, 3, \dots) \]

General Formula for Harmonics: fn = n*v / (2L)

The harmonic frequencies form an exact arithmetic progression with common ratio integer multiples:

\[ f_1 : f_2 : f_3 : f_4 : \dots = 1 : 2 : 3 : 4 : \dots \]

For a string clamped at both ends, all harmonics (both even and odd) are present in the acoustic spectrum.

The difference between any two successive harmonic frequencies equals the fundamental frequency: \[ \Delta f = f_{n+1} - f_n = \frac{(n+1)v}{2L} - \frac{nv}{2L} = \frac{v}{2L} = f_1 \]

String Fixed at One End and Free at the Other

If a string of length \( L \) is clamped rigidly at \( x = 0 \) (forcing a Node) and attached to a frictionless ring at \( x = L \) (forcing an Antinode):

The boundary conditions are:

\[ y(0, t) = 0 \quad \text{and} \quad \left( \frac{\partial y}{\partial x} \right)_{x=L} = 0 \]

Applying this to \( y(x,t) = [2A\sin(kx)]\cos(\omega t) \):

\[ \cos(kL) = 0 \implies k_n L = (2n - 1)\frac{\pi}{2} \implies \left(\frac{2\pi}{\lambda_n}\right) L = (2n - 1)\frac{\pi}{2} \]
Allowed Wavelengths and Frequencies (One End Free): \[ \lambda_n = \frac{4L}{2n - 1} \quad (n = 1, 2, 3, \dots) \] \[ f_n = \frac{(2n - 1)v}{4L} = (2n - 1) f_1 \quad \text{where } f_1 = \frac{v}{4L} \]
For a string fixed at one end and free at the other: \[ f_1 : f_2 : f_3 : \dots = 1 : 3 : 5 : 7 : \dots \] Only odd harmonics are present. Even harmonics cannot be excited.

Position of Nodes and Antinodes in Various Harmonics

For a string of length \( L \) fixed at both ends vibrating in its \( n \)-th harmonic:

1. Exact Positions of Nodes

\[ x_{\text{node}} = 0, \, \frac{L}{n}, \, \frac{2L}{n}, \, \frac{3L}{n}, \, \dots, \, L \]

2. Exact Positions of Antinodes

\[ x_{\text{antinode}} = \frac{L}{2n}, \, \frac{3L}{2n}, \, \frac{5L}{2n}, \, \dots, \, \frac{(2n-1)L}{2n} \]

Solved JEE Problem: Plucking and Touching Points

Problem: A guitar string of length \( L \) fixed at both ends is plucked at a point \( x = L/4 \) and touched lightly at \( x = L/2 \). Which harmonic will be excited?

Solution:

  • Touching the string at \( x = L/2 \) forces a Node at the center (\( x = L/2 \)). Hence, \( n \) must be an even integer (\( n = 2, 4, 6, \dots \)).
  • Plucking the string at \( x = L/4 \) requires that \( x = L/4 \) must be an Antinode (or have non-zero displacement).
  • For \( n = 2 \) (2nd harmonic): Nodes are at \( x = 0, L/2, L \); Antinodes are at \( x = L/4, 3L/4 \).
  • Conclusion: The string vibrates predominantly in its 2nd harmonic (1st overtone) with frequency \( f_2 = \frac{v}{L} \).
