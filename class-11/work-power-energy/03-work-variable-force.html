Work by a Variable Force

Calculus involving Dot Product of Vectors.

Vector Algebra of Work

The expression \(W = \vec{F}\cdot\vec{s}\) gives the work done when the force remains constant throughout the displacement.

In many physical situations, however, the force changes from point to point—a situation called a variable force, where the force is different at different locations in space.

Examples include a spring being compressed, a charge moving through a non-uniform field, or an object moving through a varying gravitational field.

For a variable force situation, when we know the path connecting \(\vec{r}_1\) and \(\vec{r}_2\), we divide the path into infinitesimally small segments:

\[ d\vec{s} = d\vec{r} = dx\,\hat{i} + dy\,\hat{j} + dz\,\hat{k} \]

Over each such segment \(d\vec{s}\), the variable force \(\vec{F} = F_x\hat{i} + F_y\hat{j} + F_z\hat{k}\) can be treated as approximately constant, allowing the work done over that infinitesimal displacement to be written as:

\[ \delta W = \vec{F} \cdot d\vec{s} = F_x\,dx + F_y\,dy + F_z\,dz \]

The total work is obtained by summing the work done over all infinitesimal segments along the path:

\[ W_C = \int_C \vec{F}\cdot d\vec{s} = \int_C \delta W \]

And now, the important question is how to write this integration so that it gives the accumulation of infinitesimal work done at each \(d\vec{s}\).

We know \(\vec{r}_1\) and \(\vec{r}_2\) — the initial and final positions, given by:

\[ \vec{r}_1 = x_1\hat{i} + y_1\hat{j} + z_1\hat{k} \qquad \vec{r}_2 = x_2\hat{i} + y_2\hat{j} + z_2\hat{k} \]

Using these, we put the appropriate coordinate limits:

\[ W_C = \int_C \delta W = \int_{x_1}^{x_2} F_x\,dx + \int_{y_1}^{y_2} F_y\,dy + \int_{z_1}^{z_2} F_z\,dz \]

Notice that information about the path is not encoded in the limits. It is encoded in how \(F_x\), \(F_y\), and \(F_z\) vary along the path.

Students are often confused about what \(F_x\) is. It is not that \(F_x\) must only be a function of \(x\)—it is simply the component of force along \(\hat{i}\), which in general can depend on \(x\), \(y\), and \(z\).

Together, two things determine how the force components are evaluated during integration: the force-field relations (such as \(F_x = f(x,y,z)\)) and the geometric relation among the coordinates themselves along the path.

Work by a variable force cannot be solved using the geometric definition of the dot product (\(\vec{F}\cdot\vec{s} = |\vec{F}|\,|\vec{s}|\,\cos\theta\)).
Calculus provides the summation tool to accumulate an infinite number of individual infinitesimal work contributions.

Where Is the Path Information?

Illustration

Consider a force field (in SI units): \(\vec{F}=x\hat{j}\). A particle moves from \(A=(0,0)\) to \(B=(1,1)\). We want to calculate the work done by this force along two different paths connecting these points: Path 1 along the straight line \(y=x\), and Path 2 along the curve \(y=x^2\).

Solution

Resolve the Cartesian components of force from the given expression (\(\vec{F}=x\hat{j}\)). We need 2D resolution only:

\[ F_x=0 \qquad F_y = x \]

Therefore, the work integral becomes:

\[ W_C = \int_{x_1}^{x_2} F_x\,dx + \int_{y_1}^{y_2} F_y\,dy = 0 + \int_{y_1}^{y_2} F_y\,dy = \int_0^1 x\,dy \]

The integration limits are determined by the initial and final \(y\)-coordinates:

\[ A(x_1,y_1) = (0,0) \qquad B(x_2,y_2) = (1,1) \]

We cannot solve this integral without knowing the path equation.

That is how we know the value of \(x\) at each point during the motion — from the information of the path followed.

Path 1: Straight-Line Path

The particle travels along the straight line \(y=x\).

Substitute this path relation into the work integral:

\[ \begin{aligned} W_1 &= \int_0^1 x\,dy \\ &= \int_0^1 y\,dy \\ &= \left[\frac{y^2}{2}\right]_0^1 \end{aligned} \] \[ \boxed{W_1 = \frac{1}{2}\,\text{J}} \]

Path 2: Curved Path

The particle travels along the curve \(y=x^2\).

Expressing \(x\) in terms of \(y\): \(x = \sqrt{y}\) (since \(x \ge 0\) along this path).

Substitute this path relation into the same work integral:

\[ \begin{aligned} W_2 &= \int_0^1 x\,dy \\ &= \int_0^1 \sqrt{y}\,dy \\ &= \left[\frac{2}{3}y^{3/2}\right]_0^1 \end{aligned} \] \[ \boxed{W_2 = \frac{2}{3}\,\text{J}} \]

What Have We Learned?

Notice that both cases have:

  • The same force field: \(\vec{F}=x\hat{j}\).
  • The same initial position: \(A=(0,0)\).
  • The same final position: \(B=(1,1)\).
  • The same integration limits: \(0\) to \(1\), along the \(y\)-coordinate.

Yet, the work done is different:

\[ W_1 = \frac{1}{2}\,\text{J} \qquad W_2 = \frac{2}{3}\,\text{J} \]

So where did the path information enter the calculation?

It entered through the relationship between \(x\) and \(y\) along the path. This relationship determined the value of the force component \(F_y=x\) at each point during the motion.

The integration limits specify the initial and final coordinate values.
They do not, by themselves, specify the path.
The path information enters through the coordinate relationships used to evaluate the force components during integration.
Thus, even when the force field and the endpoints remain unchanged, changing the path can change the accumulated work.

Limits of Integration — Direction Information

It's not that the limits do not contain any information about displacement. The path information may be contained in the expressions, but information about the direction of traversal is determined by the limits.

Illustration

Consider projectile motion along a parabolic path. A particle of mass \(m\) is projected ground-to-ground with speed \(u\) at an angle \(\theta\) with the horizontal. Calculate the work done by the gravitational force in two cases: when the particle moves from the ground to maximum height, and when the particle returns from maximum height back to the ground.

Solution

Formulate the expression for gravitational force in Cartesian component form: \(\vec{F}_g = -mg\hat{j}\). We need 2D resolution only:

\[ F_x = 0 \qquad F_y = -mg \]

To formulate the work integral, we need the coordinates of the key points. The particle is projected from \(O(0,0)\). Let the range be \(R\) and maximum height be \(H\). The point of maximum height is \(A(R/2, H)\) and the landing point is \(B(R,0)\). We express \(R\) and \(H\) in terms of the given quantities \(u\) and \(\theta\):

\[ H = \frac{u^2\sin^2\theta}{2g} \qquad R = \frac{4H}{\tan\theta} \]

Therefore, the work integral becomes:

\[ W_C = \int_{x_1}^{x_2} F_x\,dx + \int_{y_1}^{y_2} F_y\,dy = 0 + \int_{y_1}^{y_2} -mg\,dy \]

The integration limits are determined by the initial and final coordinates, and hence they determine the direction of traversal along the path.

Path 1: From \(O\) to \(A\)

For Path 1, the coordinates are:

\[ O(x_1,y_1) = (0,0) \qquad A(x_2,y_2) = (R/2,H) \]

Substitute these as limits into the work integral:

\[ \begin{aligned} W_1 &= \int_{0}^{H} -mg\,dy \\ &= -mg\,\int_{0}^{H} dy \\ &= -mg\,\left[y\right]_{0}^{H} \end{aligned} \] \[ \boxed{W_1 = -mgH = -\frac{1}{2}mu^2\sin^2\theta} \]

Path 2: From \(A\) to \(B\)

For Path 2, the coordinates are:

\[ A(x_1,y_1) = (R/2,H) \qquad B(x_2,y_2) = (R,0) \]

Substitute these as limits into the work integral:

\[ \begin{aligned} W_2 &= \int_{H}^{0} -mg\,dy \\ &= -mg\,\int_{H}^{0} dy \\ &= -mg\,\left[y\right]_{H}^{0} \end{aligned} \] \[ \boxed{W_2 = +mgH = +\frac{1}{2}mu^2\sin^2\theta} \]

What Have We Learned?

Notice that both cases had the same force, \(\vec{F}_g = -mg\hat{j}\), while the path and direction of vertical traversal were different.

The differential \(dy\) represents a general signed infinitesimal displacement along \(\hat{j}\). We do not manually change its sign to \(-dy\) when the particle moves vertically downward.

The direction of traversal is represented by the order of the integration limits.

During upward motion, the y-coordinate increases, so the limits are from \(0\) to \(H\) and (\(dy \gt 0\)). During downward motion, the y-coordinate decreases, so the limits are from \(H\) to \(0\) and (\(dy \lt 0\)).

Thus, the integration limits carry information about the direction of traversal along the coordinate axis.

We let the variable force change its magnitude and direction as per the co-ordinate and let the limits decide the direction of traversal.

Variable Force \(F(x)\)

When we write a force as a function of position, such as the spring force

\[ F(x)=-kx \]

many students interpret it as a scalar equation. However, it is actually a one-dimensional vector equation.

The displacement coordinate \(x\) is a signed quantity. Its magnitude gives the distance from equilibrium, while its sign specifies the direction.

Since the force depends on \(x\), both the magnitude and direction of the force are determined by the magnitude and sign of \(x\).

For example, if \(x=2\text{ m}\), the object is located 2 m on the positive side of the chosen axis (lets say upwards).

The spring force is then \(F = -2k\)

That is actually a vector equation and it means that the force has magnitude \(2k\) and acts in the opposite direction of displacement (that is downwards).

The sign carries the directional information.

To make the vector nature explicit, let the positive direction be represented by the unit vector \(\hat{i}\). The spring force can then be written as

\[ \vec{F}=-kx\,\hat{i} \text{ (same as: } F(x) = -kx \text{ )} \]

Consider a general infinitesimal displacement along the same axis:

\[ d\vec{x}=dx\,\hat{i}. \]

The general variable quantity \(dx\) is signed (its a 1D vector variable). A positive value represents displacement along \(+\hat{i}\), while a negative value represents displacement along \(-\hat{i}\).

The infinitesimal work done by the force is

\[ dW = \vec{F}\cdot d\vec{x} = -kx\hat{i} \cdot dx\hat{i} = -kxdx = F(x)dx \]

Thus,

\[ dW = F(x)\,dx \]

is simply the one-dimensional form of the vector dot product. The vector nature has not disappeared; it is encoded in the signs of \(F(x)\) and \(dx\).

The sign of \(dx\) determines the direction of an infinitesimal displacement. The overall direction of motion is reflected in the limits of integration, which specify the initial and final positions of the motion.

Graphical Interpretation: Area Under the F–x Graph

The integral \(\int_{x_1}^{x_2} F(x)\,dx\) represents the area enclosed between the \(F\text{–}x\) curve, the \(x\)-axis, and the vertical lines at \(x = x_1\) and \(x = x_2\).

  • If the curve lies above the \(x\)-axis (force in the direction of displacement), the work is positive.
  • If the curve lies below the \(x\)-axis (force opposing displacement), the work is negative.
  • The net work is the algebraic sum of all such areas.
Graphical methods are extremely useful in JEE problems where \(F(x)\) is given as a piecewise linear function or a simple shape. Count the area above the axis as positive and below as negative.

The Spring Force: A Key Example

A spring obeying Hooke's Law exerts a restoring force proportional to its extension or compression:

\[F = -kx\]

Here, \(k\) is the spring constant (stiffness) and \(x\) is the displacement from the natural (unstretched) length. The negative sign indicates the force is always directed back towards the equilibrium position.

The work done by the spring force when the spring is compressed or stretched by \(x\) from its natural length is:

\[W_{\text{spring}} = \int_0^x (-kx')\,dx' = -\frac{1}{2}kx^2\]

The work done by an external agent stretching the spring from 0 to \(x\) is:

\[W_{\text{external}} = +\frac{1}{2}kx^2\]
The work done by the spring force is always negative when the spring is being deformed from its natural length, because the spring force opposes the displacement. This energy is stored as elastic potential energy.

General Work by Spring Between Two Positions

When a spring moves from compression/extension \(x_1\) to \(x_2\), the work done by the spring force is:

\[W_{\text{spring}} = \int_{x_1}^{x_2} (-kx)\,dx = \frac{1}{2}kx_1^2 - \frac{1}{2}kx_2^2\]

This equals the decrease in the spring's potential energy, which is the defining property of a conservative force.

Important Observations

  • Work depends on the path and the force law — for non-conservative forces, the same starting and ending positions can yield different work for different paths.
  • For a linear force like the spring, the \(F\text{–}x\) graph is a straight line through the origin, and the area is a triangle: \(W = \frac{1}{2} \times \text{base} \times \text{height}\).
  • When the displacement is in the same direction as the axis and the force is one-dimensional, the vector integral reduces to the scalar integral shown above.
