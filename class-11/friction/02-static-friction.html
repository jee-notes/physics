Static Friction: The Self-Adjusting Force

Preventing motion through perfect equilibrium.

1. Self-Adjusting Nature

Static friction (\(f_s\)) is a force that operates when there is a tendency for relative motion but no actual sliding. It is called self-adjusting because it exactly matches the applied force (\(F_{ext}\)) in magnitude and acts in the opposite direction.

As long as the body is at rest: \( f_s = F_{ext} \)

2. Limiting Friction

There is a maximum value beyond which static friction cannot grow. This maximum value is called Limiting Friction (\(f_{L}\)).

\[ f_{L} = \mu_s N \]
  • \(\mu_s\) is the coefficient of static friction (depends on the materials).
  • \(N\) is the normal reaction force.

3. The Inequality

Static friction is not a fixed value given by a formula; it is constrained by an inequality:

\[ 0 \leq f_s \leq \mu_s N \]
Remember: \(f_s\) only equals \(\mu_s N\) when the body is on the "verge of sliding." In all other resting states, it is strictly less.
