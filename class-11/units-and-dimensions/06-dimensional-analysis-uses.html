Uses of Dimensional Analysis

Practical applications of dimensions in solving physics problems.

1. Checking Accuracy of Equations

By taking the dimensions of both sides of an equation, we can determine if it is "dimensionally correct".

Note: A dimensionally correct equation may still be physically incorrect (e.g., missing a constant factor), but a dimensionally incorrect equation is always physically wrong.

2. Converting Units

Dimensions provide a systematic way to convert a measurement from one system of units (like SI) to another (like CGS).

\[ n_2 = n_1 \left( \frac{M_1}{M_2} \right)^a \left( \frac{L_1}{L_2} \right)^b \left( \frac{T_1}{T_2} \right)^c \]

3. Deriving Relations

If we know which factors a physical quantity depends on, we can use dimensional analysis to derive the relationship between them.

\[ T \propto m^a l^b g^c \] \[ [T^1] = [M^a L^b (LT^{-2})^c] \] \[ \implies T = K \sqrt{\frac{l}{g}} \]
