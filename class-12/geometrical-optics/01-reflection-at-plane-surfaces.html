Reflection at Plane Surfaces

The foundation of image formation by smooth, flat boundaries.

Image Formation by Plane Mirrors

An image is formed when light rays originating from a point object, after reflection, meet or appear to meet at another point. In a plane mirror, reflection transforms the incident system of rays into a reflected system, and the image is determined by the behavior of these reflected rays.

For a plane mirror, the nature of the image depends on the nature of the object:

  • Real Object: Reflected rays diverge → the image is virtual.
  • Virtual Object: Reflected rays converge → the image is real.

For extended objects, the image is formed by considering each point of the object. The overall image is characterized by:

  • Orientation: Erect or inverted
  • Scale: Magnified, diminished, or same size

Characteristics of the image of a real extended object in a plane mirror:

  1. The image is always virtual and erect.
  2. The image is of the same size as the object (magnification \( m = +1 \)).
  3. The image distance from the mirror is equal to the object distance from the mirror.
  4. The image is laterally inverted.

This behavior can be expressed mathematically. If the mirror lies in the \(YZ\) plane (at \(x = 0\)) and an object point is at \((x, y, z)\), then the image point is formed at: \[ (x, y, z) \;\longrightarrow\; (-x, y, z) \]

Field of View and Multiple Reflections

The region from which an observer can see the image of an object in a mirror is known as the field of view. It is determined by tracing the extreme reflected rays from the edges of the mirror to the observer's eyes.

To see the full image of oneself in a plane mirror, the minimum length of the mirror required is exactly half the height of the person. This is independent of the distance of the person from the mirror.

Multiple Reflections from Two Inclined Mirrors

When two plane mirrors are placed at an angle \(\theta\) to each other, an object placed between them forms multiple images due to repeated reflections. The number of images, \(n\), formed depends on the angle \(\theta\).

Let \( N = \frac{360^\circ}{\theta} \).

  1. If \( N \) is an even integer, the number of images formed is \( n = N - 1 \), symmetrically or asymmetrically placed object.
  2. If \( N \) is an odd integer:
    • For an object placed symmetrically on the angle bisector: \( n = N - 1 \)
    • For an object placed asymmetrically: \( n = N \)
  3. If \( N \) is a fraction, the number of images is equal to the integral part of \( N \).

All images formed by two inclined mirrors lie on a circle passing through the object, with its center at the intersection point of the two mirrors.

Velocity of Image in Plane Mirrors

When an object or the mirror itself moves, the image formed by the plane mirror also moves. We can analyze this by taking the position vector of the object and image relative to the mirror.

Let the mirror lie in the \(YZ\) plane. The direction perpendicular to the mirror is the \(x\)-axis, and vectors parallel to the mirror lie in the \(YZ\) plane.

  1. Velocity components parallel to the mirror: The image moves with the same velocity as the object. \[ \vec{v}_{i,\parallel} = \vec{v}_{o,\parallel} \]
  2. Velocity components perpendicular to the mirror: The velocity of the image relative to the mirror is equal and opposite to the velocity of the object relative to the mirror. \[ \vec{v}_{i,\perp} - \vec{v}_{m,\perp} = - (\vec{v}_{o,\perp} - \vec{v}_{m,\perp}) \] \[ \Rightarrow \vec{v}_{i,\perp} = 2\vec{v}_{m,\perp} - \vec{v}_{o,\perp} \]

Example: Moving Mirror and Object

Suppose an object is moving towards a stationary plane mirror with a speed of \( 5 \text{ m/s} \) perpendicular to it (\( \vec{v}_{o,\perp} = 5\hat{i} \)). The image velocity perpendicular to the mirror will be: \[ \vec{v}_{i,\perp} = 2(0) - (5\hat{i}) = -5\hat{i} \text{ m/s} \] The relative velocity of separation or approach is thus \( 10 \text{ m/s} \).

Now, if the object is stationary (\(\vec{v}_{o,\perp} = 0\)) and the mirror moves towards the object with speed \( 2 \text{ m/s} \) (\(\vec{v}_{m,\perp} = -2\hat{i}\)), the image velocity is: \[ \vec{v}_{i,\perp} = 2(-2\hat{i}) - 0 = -4\hat{i} \text{ m/s} \] Thus, if a mirror moves with speed \(v\) towards a stationary object, the image moves with speed \(2v\).
