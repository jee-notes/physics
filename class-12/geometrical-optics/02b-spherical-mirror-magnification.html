Mirror Magnification

Mirror Magnification for Spherical Mirrors.

Mirror Formula and Magnification

The relationship between the object distance (\(u\)), image distance (\(v\)), and focal length (\(f\)) for a spherical mirror is encapsulated in the mirror formula. This equation is paramount for solving optical image formation problems.

The Mirror Formula

\[ \frac{1}{v} + \frac{1}{u} = \frac{1}{f} \]

Where:

  • \(u\) = object distance from pole.
  • \(v\) = image distance from pole.
  • \(f\) = focal length of the mirror.

Always substitute values of \(u, v, f\) with their proper signs based on the sign convention.

Lateral (Transverse) Magnification (\(m\))

Magnification describes how large or small the image is compared to the object. It is defined as the ratio of the height of the image (\(h_i\)) to the height of the object (\(h_o\)).

\[ m = \frac{h_i}{h_o} \]

Using similar triangles in the geometric proof of the mirror formula, we derive the relation:

\[ m = -\frac{v}{u} = \frac{f}{f - u} = \frac{f - v}{f} \]

Interpreting Magnification (\(m\)):

  • If \(m\) is negative (\(-\)), the image is inverted. Inverted images formed by single mirrors are always real.
  • If \(m\) is positive (\(+\)), the image is erect. Erect images formed by single mirrors are always virtual.
  • If \(|m| > 1\), the image is magnified (enlarged).
  • If \(|m| < 1\), the image is diminished.
