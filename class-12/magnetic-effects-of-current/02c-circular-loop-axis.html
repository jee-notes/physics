Magnetic Field on the Axis of a Circular Loop

Field at an arbitrary point on the axis of a current loop.

Setup and Geometry

Consider a circular loop of radius \(R\) carrying a steady current \(I\). The loop lies in the XY-plane and is centered at the origin.

We wish to determine the magnetic field at a point P located on the Z-axis at a distance \(z\) from the center of the loop.

Every point on the loop is at the same distance \(R\) from the center. A differential current element located at position \((x,y)\) on the loop has tangent vector \(d\vec l\).

The position vector from this current element to the observation point \(P\) is

\[ \vec r = z\hat{k} - (x\hat{i} + y\hat{j}) \]

The magnitude of this vector is

\[ r = \sqrt{R^2 + z^2} \]

Because the point \(P\) lies on the axis of the loop, every current element is at the same distance from \(P\). This symmetry greatly simplifies the calculation.

Applying the Biot–Savart Law

The Biot–Savart law gives the magnetic field contribution from a small current element:

\[ d\vec B = \frac{\mu_0}{4\pi} \frac{I\, d\vec l \times \hat r}{r^2} \]

The differential current element \(d\vec l\) lies along the tangent to the circular loop in the XY-plane.

The vector \( \vec r \) connecting the current element to point \(P\) has both radial and axial components.

As a result, the magnetic field contribution \(d\vec B\) from each element also has two components:

  • A component along the Z-axis
  • A component in the radial direction within the XY-plane

However, for every current element on the loop there exists another element diametrically opposite to it. The radial components of their magnetic field contributions cancel due to symmetry.

Only the components along the Z-axis add constructively.

Thus the net magnetic field at point \(P\) must lie along the Z-axis.

Evaluating the Axial Component

The magnitude of the magnetic field contribution from a current element is

\[ dB = \frac{\mu_0 I}{4\pi} \frac{dl \sin\alpha}{r^2} \]

where \( \alpha \) is the angle between \(d\vec l\) and \(\vec r\).

From the geometry of the loop,

\[ \sin\alpha = \frac{R}{r} \]

Substituting this relation gives

\[ dB = \frac{\mu_0 I}{4\pi} \frac{R\,dl}{r^3} \]

Only the component along the axis contributes to the net field. This component is

\[ dB_z = dB \cos\theta \]

where

\[ \cos\theta = \frac{z}{r} \]

Substituting,

\[ dB_z = \frac{\mu_0 I}{4\pi} \frac{R z}{r^4}\, dl \]

Integration over the Loop

Since \(r = \sqrt{R^2+z^2}\) is constant for all elements of the loop, the only variable in the integral is \(dl\).

\[ \int dl = 2\pi R \]

Therefore

\[ B_z = \frac{\mu_0 I}{4\pi} \frac{R z}{r^4} (2\pi R) \]

Substituting \(r = \sqrt{R^2+z^2}\),

\[ \boxed{ B = \frac{\mu_0 I R^2}{2(R^2+z^2)^{3/2}} } \]

The magnetic field at any point on the axis of a circular current loop is directed along the axis of the loop.
